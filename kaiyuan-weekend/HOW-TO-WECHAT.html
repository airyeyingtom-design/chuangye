如何把这个能动长页放到公众号里

微信推文编辑器不能直接塞进整页滚动动画网页。业界通用做法是：H5 放在 HTTPS 域名上，公众号里用「入口」把它打开。

推荐做法（最稳）

  1. 把本目录部署到 HTTPS（GitHub Pages / 你自己的服务器 / 腾讯云静态网站均可）。
  2. 拿到链接，例如：https://你的域名/kaiyuan-weekend/
  3. 在公众号后台写一篇短推文作封面介绍（可放 1 张封面图 + 3 句话）。
  4. 文末打开「原文链接」，粘贴上面的 H5 地址；或在自定义菜单加「本周指南」指向该链接。
  5. 粉丝点「阅读原文 / 菜单」→ 全屏打开丝滑长页。
为什么不直接贴进正文？

公众号正文只支持有限 HTML。真正「往下滑动画惊人」的，几乎都是外链 H5（或小程序）。

想「看起来像嵌在推文里」

  • 135 编辑器 / 秀米 / 壹伴：可做部分 SVG、点击展开；复杂滚动仍不如独立 H5。
  • 小程序：用 web-view 打开同一链接（需业务域名校验）。
  • 视频号 / 朋友圈：可另出竖版封面引流到同一 H5。

上线前检查清单

  • 必须是 https://，微信内才能顺畅打开。
  • 手机微信里实机滑一遍（iOS + Android 各一次）。
  • 封面图建议 2.35:1 或 1:1，推文首图单独导出，不要截整页长图。
  • 文案日期、楼层、价格以商场最新通知为准再发。

本仓库路径

页面文件：kaiyuan-weekend/index.html
本地预览：用手机访问部署后的地址，或电脑开开发者工具手机模式。

可选加强

  • 接微信 JS-SDK：自定义分享标题、描述、缩略图。
  • 加「一键导航」：腾讯地图 / 高德 schema。
  • 活动过期后改目录日期，或做下一期「周末指南」复用模板。
