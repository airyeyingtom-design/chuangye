E2-lite：迷你公众号动效工具

你问「能不能先做 E2 一样的工具再做内容」——完整 E2.COOL 是商业产品，这里做的是能开工的迷你版。

它能做什么

  • 积木拼装：封面 / 文案 / 大图 / 捏泡泡 / 活动卡 / 收尾
  • 手机预览：下滑渐入 + 可点破泡泡
  • 导出独立 H5（推荐）
  • 导出微信 SVG HTML（E2 同类思路的简化版）

它不等于 E2.COOL

E2 有模板市场、融媒体标准认证、复杂滚动时间轴、音频组件美化等。E2-lite 不复制其版权模板，也不声称兼容其全部黑科技；目标是让你自己能产出同方向内容。

推荐发布路径

  1. 在编辑器里改文案 → 下载独立 H5
  2. 上传到 GitHub Pages / 服务器（必须 HTTPS）
  3. 公众号短推文 +「原文链接」打开 H5

微信正文粘贴

可用「复制微信 SVG」到 135 / 秀米 / E2 等编辑器的 HTML 通道。官方后台直接粘贴经常丢样式或互动。捏泡泡请走 H5。

下一步可加

  • 更多积木：横向滑卡、进度章节、音频条
  • 本地上传图片（现在用图片 URL）
  • 滚动驱动更强的 SVG 时间轴（更接近 E2）
